SayScore PDF 사용법

[설치판 - 권장]
1. SayScorePDF-Setup-<버전>.exe를 실행합니다.
2. WSL 2가 없으면 설치 프로그램이 Windows 기능(WSL 2)만 켭니다. (Linux 배포판이나 Docker는 설치하지 않습니다)
3. 재부팅 안내가 나오면 재부팅합니다. 로그인하면 SayScore PDF가 자동으로 시작됩니다.
4. 처음 프린터를 등록할 때 Windows 관리자 확인 창에서 "예"를 누릅니다.
5. 출력할 프로그램에서 프린터로 "SayScore PDF"를 선택합니다.
6. 변환된 PDF는 %LOCALAPPDATA%\SayScorePDF\output 폴더에 저장됩니다.

[포터블 ZIP]
1. 압축을 완전히 풉니다.
2. "SayScorePDF.exe"를 실행합니다. WSL 2가 없으면 안내에 따라 Windows 기능 설치를 승인합니다.
3. 재부팅 뒤에는 "SayScorePDF.exe"를 다시 실행해야 합니다.
4. 변환된 PDF는 압축을 푼 폴더의 data\output에 저장됩니다.

주의: WSL 2 기능을 처음 설치할 때는 인터넷과 관리자 권한이 필요합니다. BIOS 가상화가 꺼졌거나 조직 정책이 설치를 막는 PC는 관리자가 먼저 허용해야 합니다.
중계 파일은 x64/ARM64용으로 동봉되어 있어 실행할 때 인터넷에서 받지 않습니다.
