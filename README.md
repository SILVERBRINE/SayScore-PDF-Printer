# SayScore PDF

Windows 인쇄 작업을 실제 Windows 프린터 드라이버와 Standard TCP/IP Port로 받아 PDF로 변환합니다.

## 실행

1. 압축을 완전히 풉니다.
2. `SayScore PDF.cmd`를 더블클릭합니다.
3. WSL 2/Docker Desktop이 없는 호환 PC에서는 설치 동의를 묻고 자동 설치를 시도합니다.
4. 설치 과정에서 재부팅을 요구하면 재부팅 후 같은 파일을 다시 더블클릭합니다.
5. 최초 실행 또는 네트워크 주소 변경 시 표시되는 Windows 관리자 확인을 승인합니다.
6. 인쇄 화면에서 `SayScore PDF`를 선택합니다.

실행기는 Docker Desktop을 시작하고, 동봉된 CPU별 오프라인 이미지로 전용 네트워크 중계기를 준비한 다음 앱을 시작합니다. 중계 이미지 생성에는 인터넷이 필요하지 않습니다. Windows 프린터 큐는 Docker/WSL 주소의 RAW 9100/UDP 161을 사용하고, 중계기는 이를 앱 전용 내부 포트 TCP 19100/UDP 1161로 전달합니다. 외부 포트와 내부 포트를 분리해 재귀 중계와 포트 고갈을 방지합니다. 재부팅이나 네트워크 변경 뒤에도 같은 실행 파일을 다시 열면 주소를 재검사합니다.

## 요구 사항

- 지원되는 64비트 Windows 10/11 클라이언트 및 하드웨어 가상화
- WSL 2와 Docker Desktop Linux 컨테이너 엔진
- 최소 8GB RAM 권장
- 최초 프린터 설치 때 관리자 권한
- x64에서는 포함된 Samsung X4305 드라이버 경로를 우선 사용합니다.
- ARM64에서는 ARM64용 드라이버 경로를 별도로 판정하며 x64 드라이버를 사용하지 않습니다.

## 새 PC에서의 한계

호환되는 일반 Windows 10/11 PC에서는 실행기가 WSL 2와 Docker Desktop 자동 설치를 시도합니다. 이 최초 설치에는 인터넷, 관리자 승인, Docker 사용 조건 확인이 필요하며 Windows 재부팅 뒤 같은 실행 파일을 한 번 더 열어야 할 수 있습니다. BIOS/UEFI 가상화 활성화, 조직 보안 정책 해제, Docker 사용권 판단은 ZIP이 대신할 수 없습니다. 관리자 권한이 없는 PC, Windows Server, 32비트 Windows, 가상화가 차단된 PC까지 포함한 문자 그대로의 "모든 PC"는 지원할 수 없습니다.

x64 실제 출력 경로는 검증했습니다. ARM64용 드라이버와 오프라인 중계 이미지는 분리해 포함하지만 ARM64 실제 장비 회귀 시험 전에는 ARM64 정상 출력을 보장하지 않습니다.

## 데이터 위치

- 생성 PDF: `data/output`
- 원본 작업 및 변환 기록: `data/jobs`
- 통신 진단 로그: `data/diagnostics`
- 현재 상태: `data/runtime-status.json`
- 중계 상태: `data/relay-runtime.json`

PC에 이미 설치된 다른 프린터나 기본 프린터 설정은 변경하지 않습니다.

## 개인정보

- 인쇄 내용, 변환된 PDF, 진단 로그는 모두 이 PC의 `data` 폴더에만 저장되며 외부로 전송하지 않습니다.
- `data/diagnostics`의 진단 파일에는 PC의 IP 주소, 프린터·드라이버 정보가 들어 있습니다. 이슈를 올릴 때 첨부하기 전에 내용을 확인하세요.
